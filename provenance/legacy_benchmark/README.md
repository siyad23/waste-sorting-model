# Superseded local benchmark records

These files preserve the local benchmark included before the documentation
was aligned with the published paper:

- `benchmark_summary.json`: the original local benchmark summary and its provenance notes.
- `per_class_metrics.csv`: the corresponding local per-class records.

They are archived for provenance and are superseded as the repository's
reported benchmark by **Table 3B** of the
[paper](https://doi.org/10.1016/j.rineng.2026.111286). Use
[../../metrics/benchmark_summary.json](../../metrics/benchmark_summary.json)
for the published training, validation, and test results.
